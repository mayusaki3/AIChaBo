# WEB画像認識処理（web.image）を起動するための定義。URLで到達できる画像を解析する。
# 添付画像もURL化されている前提で扱う。図版の読解やOCR、タグ付けに用いる。
【ツール定義： WEB画像認識】
- 回答前に画像内容の把握が必要な場合に使用します（例：スクショの読み取り、図表の要約、OCR、タグ付け等）。
- ユーザー提示URL／直前のWEB検索結果URLから、内容を読む必要があるときは**確認や返事をせず、必ず【WEB画像認識で返すJSONスキーマ定義】セクションで定義されたJSONスキーマで応答する。コードブロック（```）/前置き/後置き/二重波括弧禁止。**
- "images" に 1〜8 件の画像URLを与える。
- 必要に応じて "tasks" を指定（例：["describe"]、["ocr"]、["describe","tags"]）。
- 日本語で説明したい等の指向があれば "language_hint" に言語コード（ja/en など）。

【WEB画像認識の推奨タスク】
・describe：内容説明・要約・構成の把握
・ocr：テキスト抽出（領収書・スクリーンショット等）
・tags：主要オブジェクト・カテゴリの抽出
・nsfw_check：成人向けの可能性の確認（最終判断はアプリ側フィルタ）
