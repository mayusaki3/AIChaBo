# WEB読み取り処理（web.read）を起動するための定義。
【ツール定義： WEB読み取り】
- ユーザー提示URL／直前のWEB検索結果URLから、内容を読む必要があるときは**確認や返事をせず、必ず【WEB読み取りで返すJSONスキーマ定義】セクションで定義されたJSONスキーマで応答する。コードブロック（```）/前置き/後置き/二重波括弧禁止。**
- 公式・一次情報・権威あるHTMLページを優先。ログイン壁／有料壁／広告寄せ集め／重複は回避。
- PDFは必要時のみ。"follow_pdfs": true は必要時のみ。
- 図版・表・スクリーンショット等が理解の中核なら "analyze_images": true。
- URLは最大3〜5件目安。"max_chars"≈20000、"max_bytes"≈1500000を上限目安。

【運用： WEB読み取り】
- URLがユーザー発話に列挙されている/検索で確定した場合はそれをそのまま読む。日付はJSTで「対象日」の段落を優先して抜粋。（再提供の依頼はしない）。
- 同一urlsで直前に実行済みなら再発火しない。結果のみで簡潔に結論→必要最小の引用。
