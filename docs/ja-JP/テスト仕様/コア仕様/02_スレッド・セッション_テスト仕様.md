## COMMON-SESSION-T01-01 server session lifecycle
<!-- hldocs:sec_id=csess-t01-01 -->

### 概要

サーバーセッション（SSM）が server_id 単位で一意に生成・再利用され、  
不正入力に対しても安全に動作することを検証する。

### 前提条件

- サーバーセッション管理機構が初期化されている

### 検証内容

- 同一 server_id に対して同一セッションが取得される
- 異なる server_id 間で状態が混在しない
- 不正または欠落した server_id に対して例外が送出されない

### 期待結果

- SSM が server_id 単位で一貫した状態管理を行う
- 処理が中断されず安全側に継続される

## COMMON-SESSION-T02-01 user session isolation
<!-- hldocs:sec_id=csess-t02-01 -->

### 概要

ユーザーセッション（USM）が user_id 単位で完全に分離され、  
他ユーザーの状態が混入しないことを検証する。

### 前提条件

- ユーザーセッション管理機構が初期化されている

### 検証内容

- user_id ごとに独立した状態が保持される
- 他 user_id の操作が影響を与えない
- user_id 未指定時に安全な既定挙動を取る

### 期待結果

- USM がユーザー単位の状態分離を保証する

- スレッド・セッション仕様

## COMMON-SESSION-T03-01 thread context persistence
<!-- hldocs:sec_id=csess-t03-01 -->

### 概要

スレッドコンテキスト（TCM）が thread_id 単位で管理され、  
再起動後も整合性を保って復元されることを検証する。

### 前提条件

- スレッドコンテキスト管理機構が初期化されている

### 検証内容

- thread_id 単位で文脈が保持される
- 再起動後に文脈が復元される
- 実体の存在しない thread_id が自動的に除外される

### 期待結果

- 文脈管理がスレッド単位で完結し、破損状態でも安全に継続する

- スレッド・セッション仕様
