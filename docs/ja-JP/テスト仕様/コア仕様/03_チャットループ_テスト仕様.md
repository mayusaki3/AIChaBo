## COMMON-CHAT-T01-01 chat loop basic flow
<!-- hldocs:sec_id=cchat-t01-01 -->

### 概要

1 回のユーザー入力に対してチャットループが  
定義された不変順序で処理され、正常終了することを検証する。

### 前提条件

- チャットループ実行環境が初期化済みである
- 有効な thread context が取得可能である

### 検証内容

- 入力検証から出力確定までが順序通りに処理される
- 途中で例外が発生しても UI 層へ例外が伝播しない
- 応答が必ず文字列として返却される

### 期待結果

- チャットループが破綻せず 1 回の処理単位として完結する

### 参照仕様

- チャットループ仕様

## COMMON-CHAT-T02-01 input validation handling
<!-- hldocs:sec_id=cchat-t02-01 -->

### 概要

入力検証フェーズにおいて、不正入力が安全に処理されることを検証する。

### 前提条件

- チャットループが実行可能な状態である

### 検証内容

- 空入力が検出される
- 想定外の型が検出される
- 入力エラー時に文脈が更新されない

### 期待結果

- UI 層へは識別可能な簡潔なエラー応答が返却される
- 文脈が変更されない

### 参照仕様

- チャットループ仕様

## COMMON-CHAT-T03-01 authentication resolution guard
<!-- hldocs:sec_id=cchat-t03-01 -->

### 概要

各チャットループごとに認証解決が実行され、  
未解決時に LLM 呼び出しが行われないことを検証する。

### 前提条件

- ユーザー設定またはサーバー共有設定が存在しない状態を再現可能である

### 検証内容

- 認証解決が毎回実行される
- 認証未解決時に LLM 呼び出しが抑止される

### 期待結果

- 認証未解決状態では安全なエラー応答で終了する

### 参照仕様

- チャットループ仕様  
  <!-- hldocs:ref=doc-20260120-044900Z-CL7Q#認証解決と正規化 -->

## COMMON-CHAT-T04-01 context update atomicity
<!-- hldocs:sec_id=cchat-t04-01 -->

### 概要

チャットループの成功／失敗に応じて、  
文脈更新が原子的に行われることを検証する。

### 前提条件

- thread_id に対応する文脈が存在する

### 検証内容

- 成功時のみユーザー入力と最終出力が文脈に追加される
- 途中失敗時は文脈が更新されない

### 期待結果

- 文脈の整合性が常に維持される

### 参照仕様

- チャットループ仕様

## COMMON-CHAT-T05-01 continuation handling
<!-- hldocs:sec_id=cchat-t05-01 -->

### 概要

Continuation（継続応答）が開始条件・終了条件に従って  
制御されることを検証する。

### 前提条件

- 継続条件を満たす出力を生成可能である

### 検証内容

- トークン上限到達時に継続処理が開始される
- 最大継続回数到達時に終了する
- 無限ループに陥らない

### 期待結果

- 継続処理が安全に完了する
- 途中結果が存在する場合はそれが返却される

### 参照仕様

- チャットループ仕様
