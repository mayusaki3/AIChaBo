## COMMON-UTILS-T08-01 webread robustness
<!-- hldocs:sec_id=cutils-t08-01 -->

### 概要

Web 取得（検索／読み取り）処理が、通信失敗や抽出失敗時にも  
チャットループおよび UI を停止させず、安全側に動作することを検証する。

### 前提条件

- Web 取得ユーティリティが初期化されている

### 検証内容

- HTTP エラー発生時に例外が外部へ伝播しない
- タイムアウト発生時も処理が継続する
- 取得不能 URL がスキップされ、全体処理が継続する
- 重複 URL が正規化され、無限取得に陥らない

### 期待結果

- 失敗時は空結果（None／空配列）が返却される
- 処理が中断されず、決定的な結果が返る

### 参照仕様

- Web取得・添付・ユーティリティ仕様

## COMMON-UTILS-T09-01 attachment handling
<!-- hldocs:sec_id=cutils-t09-01 -->

### 概要

添付管理機構が、添付メタ情報の欠落や不正状態に対しても  
安全に動作することを検証する。

### 前提条件

- 添付管理ユーティリティが初期化されている

### 検証内容

- attachment_id 単位で一意に管理される
- 不正／欠落した添付メタ情報が無視される
- 単一添付の失敗が他添付へ影響しない

### 期待結果

- 正規化済み添付情報のみが返却される
- 例外が呼び出し元へ伝播しない

- Web取得・添付・ユーティリティ仕様

## COMMON-UTILS-T10-01 jsonc safe load
<!-- hldocs:sec_id=cutils-t10-01 -->

### 概要

JSONC 読み取り処理が、コメント付き JSON および  
構文エラーを含む入力に対しても安全に動作することを検証する。

### 前提条件

- JSONC 読み取りユーティリティが利用可能である

### 検証内容

- コメント付き JSON が正しく解釈される
- 不正構文時に例外で停止しない
- 同一入力に対して同一出力が返る

### 期待結果

- 不正時は空 dict が返却される
- 出力が決定的である

- Web取得・添付・ユーティリティ仕様

## COMMON-UTILS-T11-01 redact masking
<!-- hldocs:sec_id=cutils-t11-01 -->

### 概要

redact 処理が秘匿情報を確実にマスキングし、  
過剰・不足のない適切な秘匿制御を行うことを検証する。

### 前提条件

- redact ユーティリティが初期化されている

### 検証内容

- API キー等の秘匿情報がログ／出力から除去される
- 非機密情報が過剰にマスキングされない

### 期待結果

- 秘匿情報の漏洩が発生しない

- Web取得・添付・ユーティリティ仕様
