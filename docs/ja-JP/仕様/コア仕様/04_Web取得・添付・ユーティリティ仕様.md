# Web取得・添付・ユーティリティ仕様

## Purpose（存在理由）

本書は、AIChaBo コアにおける **Web取得（検索／読み取り）・添付管理・共通ユーティリティ** の仕様を定義する。  
チャットループから呼び出される補助機能群について、責務・入出力・失敗時挙動・安全条件を明確化し、  
実装を **仕様に基づいて評価可能** とすることを目的とする。

---

## Non-goals（対象外）

本書は以下を対象としない。

- 各 LLM プロバイダ固有 API の仕様
- 認証情報の保存・暗号化（別：認証・秘密ストア仕様）
- セッション／文脈の保持（別：スレッド・セッション仕様）
- チャットフロー全体（別：チャットループ仕様）

---

## 基本原則（共通）

- **安全失敗**：例外により UI／チャットループを停止させない  
- **決定性**：同一入力に対して結果が不定にならない  
- **最小責務**：各ユーティリティは単一責務に限定する  
- **ログ優先**：失敗はログに残し、呼び出し元には簡潔な結果を返す  
- **機密非露出**：秘匿情報をログ／返却値に含めない（redact 適用）

---

## Web取得（検索／読み取り）

### 目的

- LLM 応答を補助するため、Web 上の情報を取得・整形する
- チャットループに対して **副作用的** に動作する補助機能とする

### 構成

- 検索：クエリ → URL 群
- 読み取り：URL → 本文抽出 → 要約／整形

### 入力（概念）

- query（文字列）または URL
- 取得オプション（最大件数、タイムアウト等：任意）

### 出力（概念）

- 成功：本文／要約テキスト、参照 URL
- 失敗：空結果（None／空配列）

### 失敗時挙動

- タイムアウト／HTTP エラー／抽出失敗時：
  - 例外を伝播させない
  - ログに記録する
  - 空結果を返す
- 取得不可 URL：
  - 当該 URL のみをスキップし、全体処理は継続する

### ガード条件

- 無限取得防止（最大件数／回数）
- 危険 URL の拒否（必要に応じて）
- 同一 URL の重複取得防止（正規化）

---

## 添付管理（attachments）

### 目的

- UI 層から渡される添付（画像／ファイル等）を安全に扱う

### 責務

- 添付メタ情報の正規化
- 添付 ID 単位での管理
- チャットループへの受け渡し

### 入力／出力（概念）

- 入力：添付メタ情報（id、type、url／path 等）
- 出力：正規化済み添付情報（存在しない場合は空）

### 失敗時挙動

- 不正／欠落メタ情報：
  - 例外を投げない
  - 当該添付を無視し、他は継続する

### セキュリティ要件

- 添付内容をログに出力しない
- URL は必要最小限のみ保持する

---

## JSONC 読み取り（jsonc）

### 目的

- コメント付き JSON（JSONC）を安全に読み取る

### 挙動要件

- コメントを除去して JSON として解釈する
- 不正構文時：
  - 例外で停止しない
  - 空 dict を返す

### 決定性

- 同一入力に対して同一出力を返す（順序含む）

---

## ロギング（logger）

### 目的

- 障害解析および運用可視化

### 原則

- 機密情報を含めない（redact 適用）
- 例外スタックは内部ログにのみ記録する
- UI／チャット出力にログ内容を混入させない

---

## redact（秘匿情報マスキング）

### 目的

- API キー等の秘匿情報をログ／出力から除去する

### 適用範囲

- ログ出力
- 例外メッセージ
- 必要に応じてチャット出力（最小限）

### 要件

- 過剰マスキングを行わない
- マスキング漏れを許容しない

---

## prefetch（事前取得）

### 目的

- Web 取得等を事前に実行し、応答時間を短縮する

### 仕様要件

- 失敗しても本処理を妨げない
- 結果はキャッシュ的に扱ってよい（任意）

---

## thread_utils（スレッド補助）

### 目的

- スレッド ID／状態に関する補助処理
- 削除済み／無効スレッドの検出支援

### 挙動要件

- 不正／欠落 ID に対して例外を投げない
- 呼び出し側が判断可能な戻り値を返す

---

## エラーおよび例外ポリシー

- すべてのユーティリティは UI／チャットループを停止させない
- 例外は内部で捕捉し、ログに記録する
- 呼び出し元へは以下のいずれかを返す：
  - None
  - 空配列／空 dict
  - False（明示的失敗）
