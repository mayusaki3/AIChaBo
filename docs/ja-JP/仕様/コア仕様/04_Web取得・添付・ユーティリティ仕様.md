# Web取得・添付・ユーティリティ仕様

本書は、AIChaBo コアにおける **Web取得（検索/読み取り）・添付管理・共通ユーティリティ** の仕様を定義する。  
チャットループ（03）から呼び出される補助機能群について、**責務・入出力・失敗時挙動・安全条件**を明確化し、  
実装（AI生成）を仕様で評価可能にすることを目的とする。

---

## 1. スコープ

対象：
- Web 取得（検索/読み取り）
- 添付（attachments）管理
- JSONC 読み取り
- ロギング
- redact（秘匿情報マスキング）
- prefetch（事前取得）
- thread_utils（スレッド補助）

非対象：
- LLM プロバイダ API 仕様（AI層）
- 認証情報の保存（01）
- セッション/文脈の保持（02）
- チャットフロー全体（03）

---

## 2. 基本原則（共通）

- **安全失敗**：例外で UI/チャットループを停止させない
- **決定性**：同一入力に対し、結果が揺れない（または揺れ方が仕様で規定）
- **最小責務**：各ユーティリティは単一責務に限定
- **ログ優先**：失敗はログに残し、呼び出し元へは簡潔な結果を返す
- **機密非露出**：秘匿情報はログ/返却値に含めない（redact 適用）

---

## 3. Web 取得（検索/読み取り）

### 3.1 目的
- LLM の回答補助として、Web 上の情報を取得・要約する
- チャットループの一部として **副作用的** に動作する

### 3.2 構成
- 検索：クエリ → URL 群
- 読み取り：URL → 本文抽出 → 要約/整形

### 3.3 入力（概念）
- query（文字列）または URL
- 取得オプション（最大件数、タイムアウト等：任意）

### 3.4 出力（概念）
- 成功：本文/要約テキスト、参照 URL
- 失敗：空結果（None/空配列）

### 3.5 失敗時挙動
- タイムアウト/HTTP エラー/抽出失敗：
  - 例外は握りつぶす
  - ログに記録
  - 空結果を返す
- 取得不可 URL：
  - 当該 URL のみスキップし、全体は継続

### 3.6 ガード
- 無限取得防止（最大件数/回数）
- 危険 URL（任意）：必要に応じて拒否
- 同一 URL の重複取得防止（正規化）

---

## 4. 添付管理（attachments）

### 4.1 目的
- UI 層から渡される添付（画像/ファイル等）を安全に扱う

### 4.2 責務
- 添付メタ情報の正規化
- 添付 ID 単位での管理
- チャットループへの受け渡し

### 4.3 入力/出力（概念）
- 入力：添付メタ（id, type, url/path 等）
- 出力：正規化済み添付情報（存在しない場合は空）

### 4.4 失敗時挙動
- 不正/欠落メタ：
  - 例外を投げない
  - 当該添付を無視し、他は継続

### 4.5 セキュリティ
- 添付内容をログに出さない
- URL は必要最小限のみ保持

---

## 5. JSONC 読み取り（jsonc）

### 5.1 目的
- コメント付き JSON（JSONC）を安全に読み取る

### 5.2 挙動
- コメントを除去して JSON として解釈
- 不正構文：
  - 例外で停止しない
  - 空 dict を返す

### 5.3 決定性
- 同一入力は同一出力（順序含む）

---

## 6. ロギング（logger）

### 6.1 目的
- 障害解析・運用可視化

### 6.2 原則
- 機密情報を含めない（redact 適用）
- 例外スタックは内部ログにのみ記録
- UI/チャット出力にログ内容を混入させない

---

## 7. redact（秘匿情報マスキング）

### 7.1 目的
- API キー等の秘匿情報をログ/出力から除去

### 7.2 適用範囲
- ログ出力
- 例外メッセージ
- 必要に応じてチャット出力（最小限）

### 7.3 要件
- 過剰マスキングしない（可読性保持）
- マスキング漏れを許容しない

---

## 8. prefetch（事前取得）

### 8.1 目的
- Web 取得等を事前に実行し、応答時間を短縮

### 8.2 仕様
- 失敗しても本処理を妨げない
- 結果はキャッシュ的に扱ってよい（任意）

---

## 9. thread_utils（スレッド補助）

### 9.1 目的
- スレッド ID/状態の補助処理
- 削除済み/無効スレッドの検出補助

### 9.2 挙動
- 不正/欠落 ID：
  - 例外を投げない
  - 呼び出し側が判断できる戻りを返す

---

## 10. エラー/例外ポリシー（本仕様範囲）

- すべてのユーティリティは **UI/チャットループを停止させない**
- 例外は内部で捕捉し、ログに残す
- 呼び出し元へは以下のいずれかを返す：
  - None
  - 空配列/空 dict
  - False（明示的失敗）

---

## 11. 仕様-実装 照合ポイント（本書対応分）

- Web 取得が失敗してもチャットが継続するか
- 添付不正時に例外が漏れていないか
- JSONC 不正構文で空 dict にフォールバックしているか
- ログに機密情報が出ていないか
- redact が一貫して適用されているか
- prefetch 失敗が本処理を妨げていないか
- thread_utils が削除済みスレッドを安全に扱えているか
